# WAKE Engine V6 Architecture & Route Map

- **Console**: Raw source input, campaign autopilot, and quick frame generation.
- **Agents**: Tier Zero execution pack (Archivist, Strategist, Scriptwriter, Creative Director, QA Gate, Export Manifest).
- **Cluster**: Content pillars, multi-platform lanes (TikTok, Instagram, X, LinkedIn), and proof notes.
- **Vault**: Local folder intake and IP vault inventory with semantic vector search.
- **Library**: Saved sources, outputs, exports, and history ledger.
- **Instructions**: Operations guide workflow assistant.
- **Automations**: Deterministic cron scheduler, review queue, and execution logs.
- **Monitor**: Live telemetry gauges (CPU, RAM, GPU, Runtime port), sparklines, and truth map.
- **Audit**: Snapshot ledger, durability receipts, and WAL logs.
