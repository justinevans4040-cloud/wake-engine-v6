# Tier Zero Build Status

Wake Engine's content agents are promoted Tier Zero agents under the user-approved local build parameters implemented in `server/tier-zero-runtime.js`.

No separate canonical Tier Zero specification exists in the authorized repository. Tier Zero claims in this product refer only to those promoted local build parameters. They do not claim compliance with an absent external specification.

The enforced build parameters cover agent contracts, required tools, local memory, persisted A2A messages and acknowledgements, replayable handoffs, tool receipts, evidence and claim mapping, quality gates, export inspection, and per-agent completion gates.
